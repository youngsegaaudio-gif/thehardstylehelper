# Hardstyle Helper — project rules

Private commercial product. Keep the repo private.

This app is a hardstyle session coach plus a Logic Mac pack exporter.
It is not an Audio Unit. Do not advertise or code it as a VST/AU until
a separate JUCE MIDI FX exists under `native/`.

## Do

- Improve coach, arrangement, MIDI, Scripter, Mac pack zip
- Keep PluginFace usable as a compact plugin-shaped panel
- Follow `docs/SHIP.md` for anything about selling

## Do not

- Make the repo public
- Add myclaw source or API keys
- Add GPL libraries
- Scaffold a fake VST that Logic cannot load
- Turn this into a generic kick designer
