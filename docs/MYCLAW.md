# myclaw — keep it separate

myclaw is a personal AI assistant. It is not this product.

- Fork / run myclaw in its own private repo
- Do not copy myclaw source into this repo
- Do not commit `~/.myclaw/config.json` or provider keys here

Use myclaw as the studio brain that talks *to* Hardstyle Helper:

- Skill: build a rawstyle 16-bar drop in G minor, export MIDI + Scripter
- Skill: turn this session into a Logic pack
- Optional cron: write 3 track ideas

Customers never install myclaw. They get the locked helper only.
